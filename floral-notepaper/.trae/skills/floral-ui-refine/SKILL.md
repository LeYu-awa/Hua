# 花箴前端 UI 精细化

用户偏好专业 ERP 美学：**微妙阴影、清晰边框、无可见滚动条**。迭代节奏是桌面优先 → 全量移动端适配。

## 视觉规范

- **阴影**：subtle，仅卡片/浮层使用，禁用重阴影；层级靠边框与间距表达。
- **边框**：清晰但不刺眼，统一 1px 色值；禁用默认浏览器外观残留。
- **滚动条**：页面/面板滚动条不可见（overlay 或隐藏但保留滚动），必要时自定义细滚动条。
- **配色**：与 Element Plus 主题变量一致，禁止硬编码散落色值（走 CSS 变量/主题 token）。
- **圆角/间距**：遵守既有的间距标尺，禁止随意堆叠。

## 响应式

- 桌面优先，但每个改动必须验证移动端：断点处布局不破、触控目标不小于 44px、横向不溢出。
- 画布/Live2D 区域在窄屏下的缩放策略要明确（缩放 vs 平移）。

## 迭代流程

1. 先看当前页面实际结构（组件树 + 样式），再动手，禁止盲改。
2. 一轮只聚焦一组视觉问题（边框 / 间距 / 滚动条 / 断点），改完即验。
3. 视觉核对在 **Tauri 应用内**进行（WebView 行为为准），禁止用浏览器截图代替。

## 技术栈注意

- Vue 3 + TypeScript + Element Plus + ECharts。
- 双 Pixi 栈（官方 SDK v7 + legacy v8）相关渲染调整时，先确认模型路由（MOC3 v4 及以下 → 官方栈；v5 → legacy），避免改错栈。
