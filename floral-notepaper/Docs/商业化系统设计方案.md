## 一、产品定位与收费模型

### 1.1 一句话定位

> 花箴 = **写作过程记录器 + AI 共笔伙伴 + 情绪花园伴侣**，面向注重创作体验的个人写作者。

### 1.2 四层收费体系

```
┌────────────────────────────────────────────────────┐
│                  一次性买断 ¥128                      │
│            (全功能永久，AI 仍需 Token)                │
├────────────────────────────────────────────────────┤
│                  月费 ¥9.9 / 年费 ¥79                │
│   无限 AI / 全植物 / 报告 / 导出 / 云同步 / 高级皮肤  │
├────────────────────────────────────────────────────┤
│                   Token 包 (可选)                    │
│       ¥6=50次  ¥18=200次  ¥39=500次                 │
├────────────────────────────────────────────────────┤
│                   免费版 (永远免费)                    │
│  基础写作 / 7天回放 / 1株竹子 / 每日10次AI / 默认主题  │
└────────────────────────────────────────────────────┘
```

### 1.3 免费版 vs 会员版 功能矩阵

| 功能模块     | 免费版   | 会员版      | 差异逻辑               |
| ------------ | -------- | ----------- | ---------------------- |
| 笔记编辑     | 无限     | 无限        | 无差异，基础体验不打折 |
| 墨迹录制     | 7天保留  | 永久保留    | 存储成本               |
| 墨迹回放     | 有       | 有          | 无差异                 |
| AI 节点分析  | 无       | 有          | AI API 成本            |
| 写作画像报告 | 无       | 有          | AI 计算成本            |
| 回放导出视频 | 无       | 有          | 渲染消耗               |
| 共笔 AI 调用 | 10次/天  | 无限        | AI API 成本            |
| AI 身份数量  | 2种      | 5种+自定义  | 内容区分               |
| 场景模板     | 1种      | 4种全部     | 内容区分               |
| 灵感注入     | 无       | 有          | AI API 成本            |
| 重新生成     | 1次/天   | 无限        | AI API 成本            |
| 上下文窗口   | 2000字   | 10000字     | Token 消耗             |
| 植物种类     | 1株竹子  | 5种全部     | 情绪价值区分           |
| 花园多株     | 无       | 3株同时     | 情绪价值区分           |
| 限定植物     | 不可购买 | 可购买      | 虚拟消费               |
| 花园装饰     | 无       | 可购买      | 虚拟消费               |
| 养花送额度   | 有(减半) | 有(全额)    | 激励差异               |
| 主题         | 默认     | 全部+自定义 | 个性化                 |
| 云同步       | 无       | 有          | 基础设施成本           |
| 分享卡片     | 无水印   | 无水印      | 传播用                 |

## 二、用户全生命周期流程

### 2.1 新用户引导流

```
下载安装 → 注册/登录(可选) → 新用户引导3页
  │
  ├─ 第1页：欢迎来到花箴，你的写作花园
  │   画面：一株刚发芽的竹子 + 东方水墨风
  │
  ├─ 第2页：记录每一次写作旅程
  │   动画：模拟墨迹回放效果
  │
  └─ 第3页：AI 是你的共笔同桌
       动画：人和 AI 交替写作
       CTA：开始免费使用 / 立即开通会员
```

### 2.2 免费用户 → 付费转化路径

```
免费用户每日 AI 额度用尽

        ↓

触发转化弹窗（自然时机）：

  ┌─────────────────────────────────────┐
  │          🌿 今日 AI 次数已用完        │
  │                                     │
  │  继续养花可获得额度                   │
  │  当前养花进度：●●●●●○ 63/100        │
  │                                     │
  │  [继续养花赚额度]  [¥6 买Token应急]   │
  │  [¥9.9/月 无限畅写 ← 推荐]           │
  └─────────────────────────────────────┘

        ↓

三种选择分流：
  - "继续养花" → 回到写作界面（留存）
  - "买 Token" → 进入 Token 支付页
  - "开会员" → 进入会员支付页（重点推荐）
```

### 2.3 付费用户留存飞轮

```
会员写作 → 积累墨迹数据 → 花园植物生长 → AI 画像报告生成
    ↑                                                    ↓
    │                                          "你的写作报告来了"
    │                                          推送 / 桌面通知
    │                                                    ↓
    └────────── 回来看报告 ─────── 顺便写一段 ──────────────┘
```

### 2.4 流失预警与召回

| 流失阶段 | 触发条件    | 召回动作                                         |
| -------- | ----------- | ------------------------------------------------ |
| 轻度流失 | 断更 2 天   | 桌面通知："你的竹子有点渴了"                     |
| 中度流失 | 断更 7 天   | 推送："竹叶黄了，来浇浇水吧" + 赠送 3 次 AI 额度 |
| 重度流失 | 断更 30 天  | 邮件："你的花园在等你" + 植物枯萎动画 + 复活赠送 |
| 会员到期 | 续费前 3 天 | 弹窗：年费续费 8 折优惠                          |

## 四、数据模型设计

### 4.1 本地 SQLite 新增表

```sql
-- 花园植物表
CREATE TABLE plants (
    id          TEXT PRIMARY KEY,
    species     TEXT NOT NULL,          -- "bamboo"|"plum_blossom"|"orchid"|"chrysanthemum"|"lotus"
    name        TEXT,                    -- 用户自定义名字
    birth_date  INTEGER NOT NULL,        -- unix timestamp
    growth      REAL DEFAULT 0.0,        -- 0.0 ~ 100.0
    health      REAL DEFAULT 100.0,      -- 0.0 ~ 100.0
    nutrients   REAL DEFAULT 0.0,        -- 当前养分（可兑换额度）
    stage       TEXT DEFAULT 'seed',     -- "seed"|"sprout"|"growing"|"blooming"|"withered"
    bloom_count INTEGER DEFAULT 0,       -- 累计开花次数
    last_water  INTEGER,                 -- 最后写作时间
    is_active   INTEGER DEFAULT 1,       -- 是否展示在花园中
    position    INTEGER DEFAULT 0,       -- 展示位置顺序
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL
);

-- 花园装饰品表
CREATE TABLE decorations (
    id          TEXT PRIMARY KEY,
    type        TEXT NOT NULL,           -- "pot"|"background"|"effect"|"weather"
    name        TEXT NOT NULL,
    rarity      TEXT DEFAULT 'common',   -- "common"|"rare"|"epic"|"legendary"|"limited"
    is_equipped INTEGER DEFAULT 0,
    purchased_at INTEGER,
    created_at  INTEGER NOT NULL
);

-- 养分/额度变动记录
CREATE TABLE nutrient_logs (
    id          TEXT PRIMARY KEY,
    plant_id    TEXT NOT NULL,
    change_type TEXT NOT NULL,           -- "earn"|"claim"|"expire"
    amount      REAL NOT NULL,
    chars_written INTEGER,               -- 触发变动的写作字数
    note_id     TEXT,                    -- 关联笔记
    created_at  INTEGER NOT NULL
);

-- 写作连续天数记录
CREATE TABLE writing_streak (
    date        TEXT PRIMARY KEY,        -- "YYYY-MM-DD"
    chars_written INTEGER DEFAULT 0,
    session_count INTEGER DEFAULT 0,
    first_write_at INTEGER,
    last_write_at INTEGER
);

-- Token 额度（本地缓存）
CREATE TABLE token_cache (
    balance     REAL DEFAULT 0,
    daily_free  INTEGER DEFAULT 10,
    daily_used  INTEGER DEFAULT 0,
    daily_date  TEXT,                    -- 上次重置日期
    updated_at  INTEGER
);

-- 会员状态（本地缓存）
CREATE TABLE subscription_cache (
    is_active   INTEGER DEFAULT 0,
    plan_type   TEXT,                    -- "monthly"|"yearly"|"lifetime"
    expires_at  INTEGER,
    renewed_at  INTEGER,
    updated_at  INTEGER
);
```

### 4.2 云端 PostgreSQL 新增表

```sql
-- 用户表
CREATE TABLE users (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email           VARCHAR(255) UNIQUE NOT NULL,
    password_hash   VARCHAR(255) NOT NULL,
    nickname        VARCHAR(100),
    avatar_url      VARCHAR(500),
    locale          VARCHAR(10) DEFAULT 'zh-CN',
    created_at      TIMESTAMP DEFAULT NOW(),
    updated_at      TIMESTAMP DEFAULT NOW()
);

-- 订阅表
CREATE TABLE subscriptions (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID REFERENCES users(id),
    plan_type       VARCHAR(20) NOT NULL,       -- "monthly"|"yearly"|"lifetime"
    status          VARCHAR(20) DEFAULT 'active', -- "active"|"expired"|"cancelled"
    started_at      TIMESTAMP NOT NULL,
    expires_at      TIMESTAMP NOT NULL,
    cancelled_at    TIMESTAMP,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 订单表
CREATE TABLE orders (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID REFERENCES users(id),
    order_type      VARCHAR(30) NOT NULL,        -- "subscription"|"token"|"plant"|"decoration"
    product_id      VARCHAR(100) NOT NULL,       -- "monthly_plan"|"token_50"|"plant_cherry"
    amount_cents    INTEGER NOT NULL,            -- 金额(分)
    currency        VARCHAR(10) DEFAULT 'CNY',
    payment_method  VARCHAR(20),                 -- "wechat"|"alipay"
    payment_id      VARCHAR(100),               -- 第三方支付单号
    status          VARCHAR(20) DEFAULT 'pending', -- "pending"|"paid"|"refunded"|"cancelled"
    paid_at         TIMESTAMP,
    created_at      TIMESTAMP DEFAULT NOW()
);

-- Token 余额表
CREATE TABLE token_balances (
    user_id         UUID PRIMARY KEY REFERENCES users(id),
    balance         INTEGER DEFAULT 0,           -- 付费购买的 token
    bonus_balance   INTEGER DEFAULT 0,           -- 养花赠送的 token
    total_earned    INTEGER DEFAULT 0,           -- 累计获得
    total_spent     INTEGER DEFAULT 0,           -- 累计消耗
    updated_at      TIMESTAMP DEFAULT NOW()
);

-- Token 流水表
CREATE TABLE token_transactions (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID REFERENCES users(id),
    change_type     VARCHAR(20) NOT NULL,        -- "purchase"|"bonus"|"consume"|"expire"|"refund"
    amount          INTEGER NOT NULL,
    balance_after   INTEGER NOT NULL,
    reason          VARCHAR(200),
    order_id        UUID REFERENCES orders(id),
    created_at      TIMESTAMP DEFAULT NOW()
);

-- 花园云端同步表（可选，用于多设备）
CREATE TABLE garden_sync (
    user_id         UUID REFERENCES users(id),
    plant_data      JSONB NOT NULL,
    decoration_data JSONB DEFAULT '[]',
    streak_data     JSONB DEFAULT '{}',
    synced_at       TIMESTAMP DEFAULT NOW(),
    PRIMARY KEY (user_id)
);
```

### 4.3 TypeScript 前端类型定义

```typescript
// ========== 用户与会员 ==========

interface UserInfo {

  nickname: string;

interface TokenBalance {

  bonusBalance: number;

  dailyUsed: number;

  nutrientsAfter: number;

  qrCodeUrl?: string; // 扫码支付二维码

  status: "pending" | "paid" | "cancelled";

// ========== 功能权限 ==========

  canUseAllScenarios: boolean;
  canGetInspiration: boolean;
  canRegenerate: boolean;
  contextWindowLimit: number;
  inkRetentionDays: number;
  maxActivePlants: number;
  canBuyExclusivePlants: boolean;
  canBuyDecorations: boolean;
  nutrientMultiplier: number; // 会员 1.0，免费 0.5
}
```

## 七、花园-额度联动系统

### 7.1 核心算法

```typescript
// ===== 写作触发养分积累 =====
function calculateNutrientGain(
  charsWritten: number,
  streakDays: number,
  isPremium: boolean,
): number {
  // 基础比率：每 100 字 = 10 养分
  let baseNutrient = (charsWritten / 100) * 10;

  // 连续写作加成
  let multiplier = 1.0;
  if (streakDays >= 30) multiplier = 2.0;
  else if (streakDays >= 14) multiplier = 1.8;
  else if (streakDays >= 7) multiplier = 1.5;
  else if (streakDays >= 3) multiplier = 1.2;

  // 会员加成（无额外倍率，但免费版减半）
  if (!isPremium) multiplier *= 0.5;

  return Math.round(baseNutrient * multiplier);
}

// ===== 养分兑换 AI 额度 =====
function calculateClaimableCredit(nutrients: number): number {
  // 每 100 养分 = 1 次 AI 调用
  return Math.floor(nutrients / 100);
}

// ===== 植物生长计算 =====
function calculateGrowth(
  plant: Plant,
  todayChars: number,
  streakDays: number,
): { newGrowth: number; newHealth: number; newStage: GrowthStage } {
  // 每日基础生长 = 写作字数 / 100
  let growthDelta = todayChars / 100;

  // 连续写作加速生长
  if (streakDays >= 7) growthDelta *= 1.3;

  // 健康值：写作 → 恢复，不写 → 衰减
  let healthDelta = todayChars > 0 ? +5 : -3;
  let newHealth = Math.max(0, Math.min(100, plant.health + healthDelta));

  // 生长阶段判定
  let newGrowth = Math.min(100, plant.growth + growthDelta);
  let newStage: GrowthStage;
  if (newHealth <= 10) newStage = "withered";
  else if (newGrowth >= 90 && plant.bloomCount === 0) newStage = "blooming";
  else if (newGrowth >= 60) newStage = "growing";
  else if (newGrowth >= 20) newStage = "sprout";
  else newStage = "seed";

  return { newGrowth, newHealth, newStage };
}

// ===== 每日 Token 重置 =====
function resetDailyQuota(tokenCache: TokenCache): TokenCache {
  const today = new Date().toISOString().split("T")[0];
  if (tokenCache.dailyDate !== today) {
    return {
      ...tokenCache,
      dailyUsed: 0,
      dailyDate: today,
    };
  }
  return tokenCache;
}

// ===== AI 调用前检查额度 =====
function checkAIAccess(
  tokenCache: TokenCache,
  subscriptionCache: SubscriptionCache,
): { allowed: boolean; reason?: string; remainingFree: number } {
  resetDailyQuota(tokenCache);

  // 会员无限
  if (subscriptionCache.isActive) {
    return { allowed: true, remainingFree: -1 };
  }

  // 免费用每日额度
  const freeRemaining = tokenCache.dailyFree - tokenCache.dailyUsed;
  if (freeRemaining > 0) {
    return { allowed: true, remainingFree: freeRemaining };
  }

  // 用付费/garden bonus token
  if (tokenCache.balance > 0) {
    return { allowed: true, remainingFree: 0 };
  }

  return {
    allowed: false,
    reason: "no_quota",
    remainingFree: 0,
  };
}

// ===== AI 调用后扣费 =====
async function consumeAIQuota(
  tokenCache: TokenCache,
  subscriptionCache: SubscriptionCache,
): Promise<TokenCache> {
  const today = new Date().toISOString().split("T")[0];
  let newCache = { ...tokenCache };

  if (subscriptionCache.isActive) {
    // 会员不扣额度
    return newCache;
  }

  // 先用免费额度
  if (newCache.dailyDate === today && newCache.dailyUsed < newCache.dailyFree) {
    newCache.dailyUsed++;
    return newCache;
  }

  // 再用付费/garden bonus token
  if (newCache.balance > 0) {
    newCache.balance--;
  }

  return newCache;
}
```

### 7.2 每日结算流程

```
每天首次打开应用时执行：

1. 检测今日是否有写作记录
   ├─ 有 → streak 连续 +1 → 更新连续天数
   └─ 无 → 检测昨天是否有记录
           ├─ 昨天有 → 今天还没写，暂不打断
           └─ 昨天无 → streak 归零

2. 健康值衰减计算
   └─ 昨天写了吗？
       ├─ 写了 → 健康值 +5
       └─ 没写 → 健康值 -3
           └─ 健康值 < 20 → 植物变憔悴
           └─ 健康值 < 10 → 植物枯萎

3. Token 每日重置
   └─ 对比 dailyDate → 新的一天 → dailyUsed = 0

4. 会员过期检测
   └─ 对比 expiresAt → 过期 → 降级为免费版功能
```

## 八、风控与防作弊

### 8.1 AI 调用防刷

```rust
// Rust 端防刷逻辑
struct RateLimiter {
    // 滑动窗口计数
    calls_per_minute: u32,       // 每分钟最多 10 次
    calls_per_hour: u32,         // 每小时最多 100 次
    recent_calls: Vec<u64>,      // 最近调用时间戳
}

impl RateLimiter {
    fn check(&mut self) -> Result<(), RateLimitError> {
        let now = current_timestamp();
        // 清理过期记录
        self.recent_calls.retain(|t| now - t < 3600);

        if self.recent_calls.iter().filter(|t| now - *t < 60).count() >= self.calls_per_minute {
            return Err(RateLimitError::TooManyRequests);
        }

        self.recent_calls.push(now);
        Ok(())
    }
}
```

### 8.2 养花送额度防作弊

| 风险                   | 应对策略                                    |
| ---------------------- | ------------------------------------------- |
| 用户粘贴大段文字刷养分 | 粘贴不计入养分数，只统计键盘逐字输入        |
| 用户按住一个键刷字数   | 检测输入模式：单字符重复超过 50 次暂停计数  |
| 用户导入外部文档刷字数 | import 内容不计入当日写作字数               |
| 修改系统时间刷连续天数 | 使用云端时间戳校验，本地时间偏差 > 24h 告警 |

### 8.3 Token 安全

```typescript
// Token 消耗以云端为准，本地仅做缓存
// 每次 AI 调用流程：
// 1. 本地检查缓存 → 确认有额度
// 2. 调用云端 API → 云端扣费
// 3. 更新本地缓存

async function safeAICall(provider: ProviderConfig, messages: Message[]): Promise<string> {
  // Step 1: 本地预检
  const preCheck = await checkAIAccess(tokenCache, subCache);
  if (!preCheck.allowed) {
    throw new AIQuotaExhaustedError(preCheck.reason);
  }

  // Step 2: 先云端扣费再调用 AI
  await cloudApi.consumeToken({
    amount: 1,
    reason: "cowrite_turn",
    clientTimestamp: Date.now(),
  });

  // Step 3: 调用 DeepSeek
  const response = await callDeepSeek(provider, messages);

  // Step 4: 更新本地缓存
  updateLocalTokenCache();

  return response;
}
```
