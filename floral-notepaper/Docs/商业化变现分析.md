# 花箴 · 商业化变现分析

> 文档版本：v1.0 | 最后更新：2026-06-25

---

## 一、产品现状复盘

花箴是一个基于 **Tauri 桌面框架**的跨平台写作伴侣应用（Windows / macOS / Linux），核心产品哲学是"面向过程、本地优先、隐私安全"。当前三大产品方向：

| 方向 | 定位 | 当前状态 |
|---|---|---|
| A 墨迹回放 | 录制写作过程，可回放 + AI 标记节点 | 已实现 |
| B 共笔模式 | 人和 AI 像同桌一样交替写作 | 已实现 |
| C 写作花园 | 虚拟植物反映写作习惯，无声陪伴 | 规划中 |

## 二、核心收费模型：Freemium + Token + 订阅

三重收费叠加，最大化 ARPU。

### Tier 1：免费版（引流）

| 免费权益 | 限制 |
|---|---|
| 基础笔记编辑 + 本地存储 | 无限 |
| 墨迹录制 + 回放 | 保留最近 7 天录制数据 |
| 共笔模式 | 每天 10 次 AI 调用 |
| 写作花园 | 只能养一株竹子 |
| 主题切换 | 仅有默认主题 |

### Tier 2：会员订阅（核心收入）

**价格锚点：￥9.9/月 或 ￥79/年**

| 会员专属权益 |
|---|
| 无限 AI 共笔调用 |
| AI 墨迹节点分析（停顿点 / 纠结点 / 流畅点） |
| 写作画像报告（周报 / 月报 / 年报） |

## 四、"养花送额度"模型设计

### 核心规则

```
用户写 100 字 = 花园获得 10 滴"养分"
每 100 养分 = 赠送 1 次免费 AI 共笔额度
```

### 连续写作加成

| 连续天数 | 养分倍率 | 说明 |
|---|---|---|
| 1-2 天 | ×1.0 | 正常积累 |
| 3-6 天 | ×1.2 | 开始有加成 |
| 7-13 天 | ×1.5 | 一周里程碑 |
| 14-29 天 | ×1.8 | 习惯养成 |
| 30+ 天 | ×2.0 | 满额奖励 |

### 情感绑定机制

| 写作状态 | 花园反馈 | 用户心理 |
|---|---|---|
| 连续写作 | 植物茁壮生长、开花 | 成就感 |
| 断更 1-2 天 | 叶片微微低垂 | 轻微愧疚 |
| 断更 7 天 | 叶片枯黄 | 焦虑、想回来 |
| 断更 30 天 | 植物枯萎（可复活） | 舍不得之前养的 |

### 模型收益逻辑

> 用户越写 → 越离不开你 → 沉没成本越大 → 断更越舍不得花 → 回来写作 → 积累更多数据 → 更离不开

**本质**：把 AI 成本从"你直接烧钱"变成"用户用活跃行为换"。写得多的人既能自给自足（留存好），也会因为体验好而升级会员（转化好）。

## 六、实施优先级路线图

### Phase 1：防漏止损（上线前必须做）

| 优先级 | 功能 | 原因 |
|---|---|---|
| P0 | Token 计数系统 + 额度限制 | 不堵，AI API 费用失控 |

|---|---|

| P1 | 付费墙（免费 / 会员功能边界） |
| P1 | Token 购买页面 |

### Phase 3：增长循环（上线后第 2-3 月）

| 优先级 | 功能 |
|---|---|

## 七、一句话总结

> **免费体验 → AI 额度耗尽 → "养花送额度"留住 → 还不够用 → 买 Token → 觉得划算 → 订会员 → 爱上花园 → 买限定植物 → 分享朋友圈 → 带来新用户 → 循环**

你的核心护城河不是 AI 功能（竞品都能接 DeepSeek），而是**花园的情绪陪伴 + 墨迹回放的私人感**。这两个东西让用户对你的产品产生感情——有了感情，才能卖溢价。
