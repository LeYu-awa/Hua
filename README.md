# 花笺 Floral Notepaper

花笺是一款面向灵感记录、长文创作与二次元写作陪伴的桌面笔记应用。项目基于 **Tauri 2 + React + TypeScript** 构建，用本地优先的数据存储承载笔记、画布、写作事件、Agent 分析与 Live2D 陪伴能力。

它不只是一个轻量便签工具：花笺把 Markdown 编辑器、无限画布、墨迹回放、写作复盘、AI Agent 与 Live2D 花灵整合到同一个桌面工作台里，适合用于日常摘记、小说设定、世界观梳理、共创讨论和长期写作习惯观察。

## 核心能力

- **Markdown 编辑器**：支持本地笔记管理、分类、导入导出、实时预览、基础排版工具、图片粘贴与 `.md` / `.markdown` / `.txt` 文件关联。
- **无限画布**：用节点、卡片和连线组织设定、灵感、角色关系与章节结构，适合把碎片想法铺开、连接和归档。
- **墨迹回放**：记录写作过程中的插入、删除、粘贴、光标移动等事件，并按时间轴回放创作过程。
- **写作复盘**：分析流畅创作、纠结修改、结构调整、大量重写、润色优化、停顿思考等行为区间，生成可读的写作报告。
- **Agent 功能**：采集画布和写作事件，生成连接建议、语义空白提醒、停顿提示、复盘关键帧和协作段落摘要。
- **Tauri 桌面能力**：提供原生窗口、快捷便签、小窗/磁贴、文件读写、系统事件、打包发布和跨平台桌面体验。
- **Live2D 花灵**：通过 Pixi.js / Cubism 驱动 Live2D 角色，将 Agent 信号映射为表情、动作和气泡反馈。

## 功能详解

### 1. 无限画布

花笺内置两套画布体验：

- **轻量画布页**：以 SVG 节点为核心，支持新增文本节点、卡片节点、拖拽移动、编辑内容、删除节点和虚线连接。
- **共笔画布模式**：基于 tldraw 的自由画布，适合更复杂的视觉组织、草图、白板讨论和协作式创作。

画布可以绑定当前笔记或会话，保存为独立的画布文档。你可以把章节、人物、地点、伏笔、参考资料拆成节点，再通过连线表达关系。Agent 开启后，画布还会出现智能覆盖层：

- 自动发现两个节点之间可能存在的隐含连接。
- 标记语义空白区，提示还缺少哪些视角或设定。
- 将聊天、文档和画布操作串起来，让讨论成果沉淀成可追踪节点。
- 为归档和标签整理提供建议，避免灵感堆积成杂乱素材。

### 2. Markdown 编辑器

编辑器是花笺的基础写作入口，围绕“快速写、方便找、能长期保存”设计。

- 支持新建、打开、保存、删除、分类、移动分类和搜索笔记。
- 支持 Markdown 实时预览，覆盖标题、列表、引用、代码、数学公式、GFM 扩展和基础 HTML 安全渲染。
- 提供常用格式按钮：粗体、斜体、标题、分隔线、无序/有序列表、代码、引用、行内公式、块级公式等。
- 支持图片粘贴和本地图片保存，并清理不再引用的图片资源。
- 支持从外部 `.md` 文件导入、导出为 Markdown，也支持读取和保存外部文件。
- 支持主题、字体大小、Tab 缩进、背景、磁贴颜色和 AI 供应商配置。

编辑器还会记录写作过程中的“墨迹事件”。这些事件不会只保留最终文本，而是保留你如何写出来：什么时候停顿、什么时候大段删除、什么时候重排结构，后续可用于回放和复盘。

### 3. 回溯与墨迹回放

回溯功能用于观察一次写作是怎样发生的，而不是只看最后成品。

花笺会以 session 为单位记录写作事件，包括：

- 插入文本、删除文本、粘贴文本。
- 光标移动、选择范围变化。
- 不同来源的写作行为，例如主编辑器、便签窗口和画布。

在“墨迹回放”页中，你可以选择某次写作 session，使用时间轴查看文本在每个时间点的状态，并以 1x、2x、4x、8x 速度播放。系统会自动识别并标记：

- 流畅创作：连续输入、推进稳定的阶段。
- 纠结修改：频繁小幅改动、反复调整措辞的阶段。
- 结构调整：段落顺序、章节结构或大纲发生变化的阶段。
- 大量重写：删除和重写比例较高的阶段。
- 润色优化：对已有文本进行细节打磨的阶段。
- 停顿思考：长时间没有输入，可能在构思或卡住的阶段。

Agent 还会在回放时间轴上增加关键帧标记，例如进入状态、停顿点、接力点、分歧点和共识点，让复盘不只是播放记录，而是能看懂创作过程中的转折。

### 4. Agent 功能

花笺的 Agent 不是独立聊天窗口，而是嵌入写作、画布、回放和 Live2D 的后台协作者。

Agent 的数据来自真实写作上下文：

- 画布节点新增、更新、删除。
- 画布连接变化。
- 聊天消息事件。
- 写作墨迹事件。
- 历史文档与写作画像。

基于这些事件，Agent 可以提供：

- **连接建议**：发现两个灵感节点之间可能有关联，并建议建立连接。
- **语义空白提醒**：当画布内容缺少动机、冲突、结局、世界观约束等视角时，提示补充。
- **停顿关怀**：当用户长时间没有输入时，以温和方式提醒休息、换段落或继续构思。
- **焦虑提示**：当写作状态表现出反复删除、长时间停顿等信号时，给出非评价式的陪伴提示。
- **协作摘要**：在共笔和会话中识别接力、分歧、共识和关键讨论段落。
- **复盘报告**：生成本次写作的亮点、风险和下一步建议。
- **Live2D 信号**：把 Agent 判断转化为角色表情、动作和气泡文字。

Agent 支持规则引擎和 AI 供应商配置。没有供应商时，部分规则型建议仍可本地运行；配置供应商后，可以获得更完整的语义分析、归档建议和写作报告。

### 5. Tauri 桌面体验

花笺使用 Tauri 2 作为桌面层，前端保持 React 体验，后端通过 Rust 提供本地能力。

当前桌面能力包括：

- 原生主窗口，支持自定义标题栏和窗口框架。
- 快捷便签窗口，可单独打开某篇笔记。
- 磁贴窗口，可把笔记固定成桌面小卡片。
- Markdown / TXT 文件关联，支持从系统打开对应文件。
- 本地笔记、配置、图片、画布、墨迹和 Agent 数据存储。
- 通过 Tauri IPC 调用 Rust 命令，完成笔记、分类、图片、画布、回放、Agent、配置和窗口管理。
- 支持 Windows NSIS、macOS app / dmg、Linux deb / rpm / AppImage 等打包目标。

Tauri 让花笺可以在保持轻量包体和 Web 技术开发效率的同时，拥有真实桌面应用需要的文件系统、窗口、系统事件和打包能力。

### 6. Live2D 花灵

Live2D 是花笺的写作陪伴层。项目内置 `public/live2d` 模型资源，并通过 Pixi.js 与 Live2D Cubism Runtime 加载角色。

Live2D 场景分为多个层：

- 背景层：承载场景背景和氛围。
- 粒子层：用于后续扩展轻量动效。
- 角色层：加载和渲染 Live2D 模型。

Agent 可以向 Live2D 下发 `live2d_signal` 指令，指令包含情绪、动作、气泡文本和优先级。Live2D 桥接层会把这些指令转成：

- 表情切换，例如开心、困倦、担心、好奇等情绪状态。
- 动作播放，例如空闲动作或点击身体动作组。
- 气泡文案，例如“慢慢来，我在这儿。”这类陪伴反馈。

因此 Live2D 不是单纯装饰，而是和写作状态、Agent 规则、回放关键帧共同构成“花灵陪伴”体验。

## 典型使用场景

- **日常速记**：用便签窗口快速记录灵感、任务和片段。
- **长文创作**：在 Markdown 编辑器里写正文，在画布里整理人物、章节和伏笔。
- **设定管理**：用无限画布建立角色关系、世界观规则、地点和事件线索。
- **复盘写作状态**：通过墨迹回放查看卡顿点、重写区间和流畅创作阶段。
- **共创讨论**：在共笔模式中围绕文档、画布和聊天进行多人协作。
- **AI 写作陪伴**：让 Agent 和 Live2D 花灵根据写作状态给出轻量、不打扰的反馈。

## 技术栈

- **桌面框架**：Tauri 2、Rust
- **前端框架**：React 19、TypeScript、Vite
- **画布能力**：tldraw、Yjs、Supabase Realtime、自研 SVG 画布
- **Markdown**：react-markdown、remark-gfm、remark-math、rehype-katex、rehype-sanitize
- **Live2D**：Pixi.js、pixi-live2d-display、Live2D Cubism Core
- **数据与同步**：本地文件 / SQLite、Supabase、Tauri IPC
- **工程质量**：Vitest、oxlint、oxfmt、Husky、GitHub Actions

## 项目结构

```text
floral-notepaper/
├─ src/                    # React 前端源码
│  ├─ components/          # 页面、编辑器、画布、回放、设置、Live2D 入口组件
│  ├─ features/            # notes / canvas / ink / agent / live2d / windows 等功能模块
│  ├─ hooks/               # 写作事件采集等 React hooks
│  └─ locales/             # 简中、繁中、英文国际化资源
├─ src-tauri/              # Tauri / Rust 桌面端能力
│  ├─ src/services/        # 笔记、画布、墨迹、Agent、画像等本地服务
│  └─ tauri.conf.json      # Tauri 打包、窗口、协议和文件关联配置
├─ public/live2d/          # Live2D 模型资源
├─ Docs/                   # 产品文档、PRD、Agent 对接资料
└─ README.md               # 简体中文说明文档
```

## 从源码运行

### 环境要求

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/tools/install)
- [Tauri CLI 2](https://tauri.app/)

### 安装依赖

```bash
git clone https://github.com/LeYu-awa/Hua.git
cd Hua/floral-notepaper
npm install
```

### 开发模式

```bash
npm run tauri dev
```

### 构建前端

```bash
npm run build
```

### 构建桌面应用

```bash
npm run tauri build
```

### 测试与格式化

```bash
npm run test
npm run lint
npm run fmt
```
